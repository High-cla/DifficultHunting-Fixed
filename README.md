# DifficultHunting-Fixed

Multi-mod repository for Barotrauma — a collection of high-difficulty creature hunting mods and enhancements.

## Mod List

| Mod | Description | Type |
|-----|-------------|------|
| [高难狩猎修复版](./高难狩猎修复版) | Difficult Hunting fixed edition: ~60 subspecies, custom weapons, missions | XML content pack |
| [画皮增强 高难狩猎](./画皮增强%20高难狩猎) | Husk creature enhancement: Charybdis/Endworm Husk variants and missions | XML content pack |
| [新银色鱼雷](./新银色鱼雷) | New silver torpedo weapon | XML content pack |
| [自动驾驶](./自动驾驶) | Enhanced submarine autopilot system | C# plugin (LuaCs) |
| [ItemOptimizer](./ItemOptimizer) | Submarine performance optimizer, reduces per-frame overhead | C# plugin (Harmony) |

## Installation

1. Copy the desired mod folders to `Barotrauma/LocalMods/`
2. Launch the game and enable the mods in the mod menu

## Dependencies

- **自动驾驶**, **ItemOptimizer** require [LuaCsForBarotrauma](https://github.com/evilfactory/LuaCsForBarotrauma)
- XML content packs (高难狩猎修复版, 画皮增强, 新银色鱼雷) have no extra dependencies
